## How to use

1. Read `thin-table.md` category matching the task's tool/domain.
2. On a match, open the same skill's row in `semantic-table.md`, then invoke the skill by its **name/directory** (e.g. `xero-automation`).
3. For `*-automation` skills, search Rube MCP (Composio) tools for current schemas before executing.
4. Underscore/hyphen duplicates are collapsed; route to the canonical hyphen name.

## Regenerate

```bash
python scripts/generate_router.py
```

Re-runs against `~/.cc-switch/cc-switch.db` (or `--db`/`--json`) and rewrites all four files deterministically.
